Exercise 1: Six-line brief/contract implementation:
	Goal:         the one outcome, in a sentence.
	Constraints:  what it must (and must not) do. Stack, perf, style, security.
	Inputs:       what the agent starts with. Files, data, an API, an example.
	Outputs:      what exists when it's finished. Files, endpoints, behavior.
	Done-check:   the concrete test that proves it works.
	Out-of-scope: what NOT to touch, so it doesn't wander.

a. Write a brief for one feature that you want to implement
b. First, execute the done-check for a feature that doesn't exist.
c. Next, execute the brief without a done-check and see how the task is executed
d. Execute the whole brief with eval(Done-check)

Exercise 2: Create hooks, if not already done, to streamline the flow of context to respective .md files.
