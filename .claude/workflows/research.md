# W4 — Research / Investigation

Notion's shape: Define question → identify evidence requirements → batch
retrieval → deduplicate evidence → synthesize → verify critical claims.

**This is the `research` skill, directly** — read `.claude/skills/research/SKILL.md`.
Its context ladder, source-evaluation criteria, and `[UNVERIFIED]`
discipline already implement this shape exactly; nothing here restates
the procedure.

For volume beyond a few sources, `research` dispatches `researcher` (mode:
source) — one per source, in parallel — per its own "Parallel work"
section, not a separate mechanism this file introduces.
