# Designer baseline

Status: initial wiring record only. A live without-skill/with-skill comparison
is still required before treating this skill as proven value.

## Intended task

Create a design contract for one representative product surface using the
requirements in `Documents/DESIGN.docx`, including product feeling, voice,
semantic tokens, typography, layout, components, states, motion, accessibility,
and anti-patterns.

## Expected improvement to measure

Compare a fresh implementation task without the skill and with
`.claude/skills/designer/SKILL.md` loaded. Record differences in:

- invented versus semantic design tokens;
- missing responsive, loading, empty, error, and keyboard states;
- accessibility evidence;
- design decisions that remain implicit in chat;
- time, turns, and token cost.

Do not claim this baseline is completed until both runs produce quoted,
file-or-screenshot-backed evidence and the cost delta is recorded.
