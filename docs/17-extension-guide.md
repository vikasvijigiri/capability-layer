# 17 — Extension Guide

## Purpose
How to extend UAIOS with new skills, validators, and storage backends.

## Steps to Add a Skill
1. Implement skill with a clear interface.
2. Write unit and integration tests.
3. Add a manifest and examples.
4. Register with the skill router and monitor metrics.

## SDKs & Tooling
- CLI for packaging skill bundles
- Test harness for example runs
- Local sandbox for safe testing

## Contribution Checklist
- Documentation updated
- Tests added
- Security review completed
