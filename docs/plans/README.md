# Plans

`writing-plans` writes here: `YYYY-MM-DD-<feature>.md`, one file per plan.
`executing-plans` reads from here and ticks the checkboxes as it goes.

Empty so far — no plan has been written yet. This file exists so the directory
is tracked and the path referenced by both skills, `CLAUDE.md` and
`.claude/workflow.md` resolves.

A plan is not `PLAN.md`. `PLAN.md` at the repo root is ordering, dependencies
and risk across a whole effort; a file here is the task-by-task script a fresh
engineer or subagent executes, with real code and real test commands.
