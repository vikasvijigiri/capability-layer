# 08 — Token Intelligence (Optimizer)

## Purpose
Maximize value-per-token while controlling cost and latency.

## Capabilities
- Pre-run token budget estimation
- Model selection (small vs large)
- Context compression and smart retrieval
- Caching and result reuse
- Token ROI metrics and dashboards

## Policies
- Prefer small models for routine steps
- Use large models only where accuracy ROI justifies cost
