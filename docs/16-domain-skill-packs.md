# 16 — Domain Skill Packs

## Concept
Curated collections of skills and blueprints for a domain (e.g., DevOps, Data,
Security).

## Structure
- Skill manifests
- Canonical blueprints
- Example runs and tests

## Distribution
- Versioned bundles
- Dependency declarations for required tools/services

## Example Packs
- DevOps: deploy, infra-as-code, incident-diagnostics
- Data: ETL, schema migrations, data quality checks
