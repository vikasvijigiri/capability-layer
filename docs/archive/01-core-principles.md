# 01 — Core Principles

## Summary
Concrete engineering standards and rules that guide all design and
implementation decisions.

## Principles
- KISS, SOLID where applicable.
- Fail fast and observable.
- Least privilege for access and secrets.
- Keep models and tools decoupled via interfaces.

## Non-negotiables
- Never commit secrets.
- Never weaken tests to pass builds.
- Every autonomous action must be auditable.

## Deliverables
- ADRs for major decisions.
- Testable contracts for subsystems.
- Documentation for operators and maintainers.
