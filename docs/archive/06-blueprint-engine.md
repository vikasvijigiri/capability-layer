# 06 — Blueprint Engine

## Concept
Blueprints are validated, reusable solution patterns extracted from successful
runs. They are the primary artifact for scaling expertise.

## Blueprint Schema
- ID, name, tags
- Problem signature
- Preconditions
- Step-by-step workflow
- Tools and skills used
- Why it worked
- Failure cases
- Confidence & reusability score
- Last validated date

## Promotion Rules
- Only promote after N successful independent validations
- Version and deprecate when failures occur

## Retrieval
- Query by problem signature, tags, or similarity score
